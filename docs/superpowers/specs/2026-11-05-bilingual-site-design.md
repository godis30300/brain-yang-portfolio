# 中英雙語履歷網站設計規格

日期：2026-11-05  
狀態：完成

## 目標

在現有 Brain Yang 單頁履歷網站加入繁體中文與英文切換，同時維持目前的極簡白底視覺、響應式版面、隱私原則與無障礙操作。

成功條件：

- 首次載入預設顯示繁體中文。
- 訪客可在桌面與手機導覽列切換「中文／EN」。
- 所有履歷內容、導覽、按鈕、頁面標題、描述與必要的無障礙文字皆有英文版本。
- 切換後立即更新頁面，不重新載入。
- 重新整理後保留訪客上次選擇。
- JavaScript 停用或失敗時，完整繁體中文內容仍可閱讀。
- 不新增聯絡資訊、追蹤程式或第三方服務。

## 選定方案

採用單一 HTML 加翻譯字典。

中文保留為 HTML 的原始內容。可翻譯元素使用穩定的翻譯鍵，JavaScript 依目前語言套用中文或英文文字。這能避免兩套頁面內容漂移，也不會破壞現有的單頁導覽與 GitHub Pages 靜態部署。

不採用以下方案：

- 在同一頁複製中英文兩組完整內容：DOM 重複且維護成本高。
- 建立獨立中文與英文 HTML：網址清楚，但每次內容更新都需同步兩份檔案。

## 介面設計

### 語言切換器

- 放置於網站名稱與導覽選單同一列的右側控制區。
- 顯示兩個選項：「中文」與「EN」。
- 目前語言使用實心深色底與白色文字；非目前語言使用透明底。
- 控制器沿用網站現有的細框線、微圓角與留白，不加入新的主色。
- 桌面版維持單列導覽；手機版切換器與選單按鈕並列，內容選單展開於下一列。
- 列印樣式隱藏語言切換器與導覽列。

### 無障礙

- 使用按鈕而非連結，避免產生虛假導覽目的地。
- 按鈕群提供「選擇語言／Choose language」標籤。
- 目前語言按鈕使用 `aria-pressed="true"`，另一按鈕為 `false`。
- 切換後更新 `<html lang>`：中文為 `zh-Hant`，英文為 `en`。
- 保留既有焦點樣式、鍵盤操作、跳至主要內容連結與手機選單行為。
- 不在切換後強制移動焦點，避免打斷鍵盤與螢幕閱讀器使用者。

## 翻譯範圍

翻譯以下所有可見及輔助文字：

- 文件標題與 meta description
- 跳至主要內容連結
- 主要導覽、手機選單按鈕與導覽標籤
- Hero 標語、摘要與行動連結
- 關於我
- 七層能力地圖，包括「實務」與「佐證」
- 六個作品專案的名稱、日期狀態、摘要、功能或個人貢獻
- 六段工作經歷的職稱、公司名稱與工作項目
- 證照分類與需要翻譯的證照描述
- 學歷、志工與比賽資訊
- 公開連結區標題
- Footer

品牌、產品、公司正式英文名稱、技術名稱與證照代碼保留原文；中文公司名稱在英文版使用正式或通順的英文名稱，不音譯不明確的品牌。

## 程式架構

### HTML

- 中文仍是伺服器直接提供的基準內容。
- 每個需要切換的文字或屬性配置穩定翻譯鍵。
- 在導覽列加入語言切換器。
- 不改變既有區段 ID、外部連結、隱私內容與語意階層。

### JavaScript

新增獨立且界線清楚的語言功能：

1. 翻譯字典：以 `zh-Hant` 與 `en` 為頂層語言，鍵值必須一一對應。
2. 語言解析：只接受支援的語言；無有效偏好時回到繁體中文。
3. 套用翻譯：更新文字、可翻譯屬性、文件標題、meta description、`lang` 與按鈕狀態。
4. 偏好儲存：使用 `localStorage`，讀寫失敗時靜默退化，不阻止切換。
5. 事件綁定：語言按鈕觸發更新，不與既有手機選單或區段觀察器耦合。

翻譯功能不改寫 HTML 結構，也不重新建立導覽元素，因此既有事件監聽器與 `IntersectionObserver` 保持有效。

### CSS

- 新增語言切換器、選取狀態與手機配置。
- 沿用現有 CSS 變數、焦點樣式與 48rem 斷點。
- 英文較長文字不得造成水平捲動。
- 不改變作品卡片、時間軸或能力地圖的主要視覺結構。

## 狀態與資料流

1. HTML 先以繁體中文顯示。
2. JavaScript 啟動後讀取 `brain-yang-language`。
3. 若值為 `en`，套用英文；其他值一律使用繁體中文。
4. 訪客按下語言按鈕時，立即套用對應翻譯並儲存選擇。
5. 重新整理時重複上述解析。
6. 若儲存空間被封鎖，當次切換仍然有效，重新整理後回到中文。

不依瀏覽器語言自動切換，確保首次載入符合使用者指定的中文預設。

## 失敗處理

- 翻譯鍵缺少：保留目前可見中文，不顯示空白或鍵名。
- 無效儲存值：忽略並使用繁體中文。
- `localStorage` 例外：捕捉後繼續套用語言。
- JavaScript 未載入：顯示完整中文頁面。
- 英文文字較長：透過既有彈性排版與新增的控制器樣式換行，不截斷內容。

## 驗證

### 自動檢查

- 中英文翻譯鍵集合完全一致。
- 所有標記為可翻譯的元素皆有兩種語言內容。
- 語言解析對無效值回到中文。
- 儲存功能失敗不會中斷切換。
- 原有五個公開連結、隱私限制與區段 ID 不變。

### 瀏覽器檢查

- 桌面與 390px 手機寬度皆可切換。
- 鍵盤可操作兩個語言按鈕，焦點樣式清楚。
- 中文與英文版皆無水平捲動。
- 手機選單與語言切換互不干擾。
- 重新整理後維持英文偏好；清除偏好後回到中文。
- 停用 JavaScript 時完整中文內容仍可閱讀。
- GitHub Pages 部署成功後，直接檢查公開網址的中英文內容。

## 發布

直接更新 `main` 分支的 `index.html`、`styles.css` 與 `app.js`。GitHub Pages 會自動重新部署；只有在部署工作成功且公開網站通過中英文瀏覽器驗證後，才視為完成。
