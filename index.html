我維修過資料中心伺服器，也維運過船舶與總部之間的網路。這些經驗帶進了我的軟體設計工作，從智慧校園的感測器資料，到 AI-Maker 的模型訓練與部署。

關於我

我習慣沿著資料流向找問題。在九七科技，我用日誌和監控指標追查正式環境的異常。在工研院，我用 JMeter 測試 MQTT 和資料庫在負載下的表現，也為機器學習工作建置 GPU 環境。目前就讀國立清華大學資訊安全研究所。

求職方向

我在尋找軟體與 AI 開發、雲端與系統架構、資料庫管理或網路資安相關職務，全職、兼職與實習皆可。

希望工作地點在新竹縣市、台北市、新北市或桃園市，也願意遠端工作。日班或晚班皆可，錄取後一週可到職。

工程技能與實作經驗

  1. 硬體與資料中心

    實務： 診斷伺服器的 CPU、記憶體、GPU 與儲存故障，執行零件更換、光纖佈線與汰役硬碟銷毀。

    佐證： 美商科高資料中心硬體維護、晉泰企業儲存建置。持有 CCNP Data Center 與 NetApp SAN 相關證照。

  2. 作業系統與虛擬化

    實務： 在 Windows Server、Linux 與 IBM AIX 環境維護企業服務，在 VMware ESXi 上管理虛擬主機並參與備份還原演練。

    佐證： 財政部印刷廠駐點維運與晉泰虛擬化專案。相關證照包括 RHCE、LPIC-2 與 VMware VCP-NV。

  3. 網路與資訊安全

    實務： 在資料中心設定 Cisco 設備及防火牆，在船岸網路使用 VPN、衛星與行動網路串接船舶和辦公室。

    佐證： 晉泰企業網路、東方風能船岸連線與 ISO 27001 內部稽核。持有 CCNP Enterprise、CCNP Security 與 CEH。

  4. 資料庫與資料平台

    實務： 在工研院整合 PostgreSQL、MySQL 與 Redis，進行備份及效能測試，也維護過船務系統的 SQL Server 與發票系統的 Oracle。

    佐證： 工研院資料平台、東方風能與財政部印刷廠維運。持有 Oracle OCP DBA 與 MySQL Professional。

  5. AI 與 IoT

    實務： 建置 NVIDIA 驅動程式、CUDA 與 cuDNN 環境。在 AI-Maker 串接 CVAT 標註與訓練流程，以 LlamaIndex 的 RAG 流程解讀模型報告。

    佐證： AI-Maker、NB-IoT 溫室與 Smart Bin。相關認證包括 Azure AI Engineer Associate（AI-102）。

  6. 雲端與平台工程

    實務： 維運 AWS、GCP 與 GKE 正式服務，以 Jenkins 和 Helm 部署應用程式，並用 Prometheus、Grafana 與 ELK 排查異常。

    佐證： 九七科技雲端維運、AWS 智慧校園平台。持有 AWS Solutions Architect Professional、Azure Solutions Architect Expert、Google Cloud Professional Cloud Architect 與 CKA。

  7. 軟體設計與全端開發

    實務： 用 React、Next.js、Node.js 與 Python 設計 Web 平台與 API，以 Redis 和 BullMQ 排程背景任務，並撰寫測試驗證整合流程。

    佐證： 工研院全端開發、AI-Maker 訓練流程，以及分散式排程系統的 UI 與 API 整合。
